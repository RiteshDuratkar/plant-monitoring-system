HOW IT WORKS

From Sensor to Smart Decision Real-Time Monitoring & Automation

Our Smart Plant Monitoring System collects real-time data from sensors, sends it to Firebase, and updates the web dashboard instantly. Based on the data, the system automatically controls irrigation and lighting.

🌡 Sensor Data

Moisture, temperature, humidity, and light sensors collect live data.

☁ Firebase Sync

ESP8266 sends data to Firebase in real-time.

📊 Dashboard

Web UI displays live data with charts and system status.

⚙ Automation

System controls pump and light based on mode (Manual/Auto/Schedule).

OUR PROJECT

Smart Plant Monitoring & Automation System Real-time Control. Intelligent Irrigation.

This IoT-based system is designed to monitor plant health using real-time sensor data and automate irrigation intelligently. By integrating ESP8266, Firebase, and a modern web dashboard, the system ensures efficient water usage and remote plant management.
